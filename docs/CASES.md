# Política de cases

Um portfólio é uma seleção de evidências. Cada case precisa indicar: problema, papel de Pedro, período, implementação, decisões, estado, limitações, links e evidências.

## Maturidade

| Estado | Evidência necessária |
| --- | --- |
| Produção | Uso real confirmado, data e fluxo acessível ou registro verificável |
| Piloto | Escopo e usuários de teste definidos, limitações explícitas |
| Em desenvolvimento | Implementação ainda sem validação operacional completa |
| Laboratório / histórico | Experimento ou projeto anterior, sem narrativa de cliente em produção |

No ecossistema AquaFlora, manter uma linha por WooCommerce, Stock Sync, apps internos, Commerce Agent e infraestrutura. Não inferir produção de todos a partir da loja online.

## Evidências

- Métricas precisam de fonte, período e método. Na ausência deles, explicar a entrega sem inventar resultados.
- Screenshots devem ter origem, data, dimensões, alt text e revisão de dados sensíveis.
- Autorizações e depoimentos de clientes têm registros privados; publicar apenas o necessário.
- HTML, JSON e PT/EN devem contar a mesma história. Não mapear tradução pela posição visual de um card.
- Novo projeto só entra em destaque depois de demonstração estável. Não preencher três posições com projetos sem evidência.
